# 슬랙 메시지 전송 트러블 슈팅

## chat.postMessage 권한 이슈

특정 채널에 메시지를 보내기 위한 기능인 chat.postMessage의 chat:write 권한을 부여받지 못한 경우 나타나는 서버통신 메시지

```json
{"ok":false,"error":"missing_scope","needed":"chat:write:bot","provided":"incoming-webhook","warning":"missing_charset","response_metadata":{"warnings":["missing_charset"]}}
```

[해결 방법]

[Slack api 사이트](https://api.slack.com/)

상단 your apps -> 캐시워크 진입 -> 좌측 OAuth&Permissions 탭 -> Scopes 메뉴 -> Bot Token Scopes/chat:write 권한 부여 → 최상단에 Reinstall to Workspace 버튼으로 최신화

비고 : Reinstall 을 실행해도 Bot User OAuth Token 은 변경되지 않음(Reinstall 이후 사후 처리 필요없음)

## 채널에 봇 없는 경우

chat.postMessage 기능을 이용해 특정채널에 메시지를 보내려할때 실패하는경우

서버통신 실패메시지:

```json
{"ok":false,"error":"not_in_channel","warning":"missing_charset","response_metadata":{"warnings":["missing_charset"]}}

```

error: not_in_channel 은 봇이 채널에 추가되어있지 않다는 뜻으로 직접 유저가 채널에 봇을 추가해주면됩니다.

[해결 방법]

봇이 메시지를 보내야하는 채널에서 다음과같은 명령어를 통해 봇을 추가합니다.

```json
/invite @봇이름
```
